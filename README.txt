
### Production Machine Learning & Architecture Hub

Welcome to my central engineering portfolio. This repository hosts a suite of machine learning systems,
 data processing tools, and architectures built from scratch. Each system is designed to be modular,
  scalable, and easy to maintain.

Instead of writing loose, fragile scripts, this entire portfolio leverages **Object-Oriented Programming (OOP),
 strict software design patterns, and decoupled pipelines to build scalable data platforms.

### Core Architectural Phase Breakdown

My engineering workflow is split into four explicit, decoupled phases that pass data efficiently through computer system memory (RAM) without data amnesia or processing bottlenecks:



### Phase 1: Automated Satellite Data Sourcing

What I Did: Developed automated data collection engines that interface with live meteorological and satellite reanalysis APIs (like Open-Meteo). 
Key Achievement: Programmed the system to dynamically fetch multi-variate historical records (Temperature, Barometric Pressure, Humidity) across different geographical coordinates (e.g., Vienna and Melbourne) to build a robust training foundation.

### Phase 2: Object-Oriented ETL & Data Factory Pipeline

What I Did: Designed a production-grade Data Pipeline using Python Abstract Base Classes (ABCs) and strict inheritance rules. It completely abstracts the extraction and transformation stages.
Key Achievement: Optimized the pipeline to process raw data frames and structure them into contiguous blocks of C-velocity memory using NumPy, packing them into perfect PyTorch 3D matrix cubes shaped as `[Batch, Time, Features]` without throwing PyTorch memory alignment warnings.

### Phase 3: Parallel Ensemble Compute Engine

What I Did: Structured and optimized a deep, multi-head **Parallel Ensemble Neural Network Architecture** featuring dedicated attention mechanisms to read climate volatility.
Key Achievement: Rewrote the training engine into a reusable ModelTrainer class box. The pipeline injects raw RAM data matrices straight into this engine, executing backpropagation across 50 epochs and minimizing L1 Loss dynamically on available hardware (CPU/GPU).

### Phase 4: Dynamic Visualization & Evaluation

What I Did: Engineered a detached ModelEvaluator class that isolates testing data to evaluate the model's true real-world predictive validity.
Key Achievement: Fixed complex object-scoped inheritance issues by pinning scikit-learn training scalars directly to the class instance memory (self.scaler_y). This allows the system to seamlessly reverse mathematical normalization and map abstract tensor inputs back into true Celsius forecasting charts.
